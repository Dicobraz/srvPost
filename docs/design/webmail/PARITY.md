# Веб-клиент: покрытие функций Postman (матрица паритета)

Эталон — реестр команд Postman (`postman/docs/PARITY.md`, 166/170). Матрица отвечает на вопрос
владельца «все ли функции доступны в вебе»: каждая функция Postman → волна веб-клиента, либо
явное решение «не переносится» с причиной. Дизайн-эталон кадров — `docs/design/webmail/`.

Справка по цветам: у категорий письма палитра из утверждённой таблицы DESIGN.md — синие
(«Клиенты»), зелёные («Команда»), серые («Сервисы»), **розовые («Тендеры»)** и т.д. Розовый —
один из цветов палитры (с явным исключением в DESIGN.md рядом с красным безопасности), не
«специальный цвет».

| Функции Postman (группы реестра) | Веб-клиент | Волна / решение |

| contacts.* (CRUD, группы, написать, встреча, копировать адрес, меню) | Полное перенос (личные + GAL read-only) | **WEB-07** |

| tab.* (вкладки внутри окна) | **Не переносится как таковое**: в браузере вкладки даёт сама среда; композер — вкладка приложения/сплит, не дублируем средовые вкладки. Пересмотр по запросу | решение (v1) |
| view.notifications (уведомления рабочего стола) | Notification API браузера (только у установленной PWA на iOS) | **WEB-08** |
| task.* (задачи: список, поручения, блок времени) | Задачи в вебе — после v1 (S6; решения 2026-11-20 — задачи вне первого скоупа) | **WEB-17** |
| mail.mute, mail.pin (в Postman «нет») | Не переносить до появления в Postman | решение |
| update.check / update.install | N/A: веб-версия обновляется с сервера, клиенту нечего проверять | решение |
| Каналы (Telegram/Matrix, ADR 0012) | Шов в маршрутах зарезервирован, в v1 скрыт (решение владельца 20.11); брендированный веб-чат — после запуска (решение 2026-11-17) | решение |
| S/MIME подпись/шифрование | Просмотр письма с подписью — после v1 (криптопровайдеры в браузере — отдельное решение) | решение (после v1) |
