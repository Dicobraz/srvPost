# Дизайн-макеты веб-клиента (mod-webmail) — на утверждение

Макеты оболочки веб-почты до старта волны 3 (WEB-03 «Список и чтение»). Дизайн-эталон —
`postman/docs/DESIGN.md` (три-панель Outlook, без модалок, Fluent-темы, правила цвета);
мобильный паттерн — mobile Outlook (решение 2026-11-20-webmail.md, WEB-08). Стиль рамок
выровнен по утверждённым десктоп-макетам `postman/docs/design/S8-D` (пропорции, хром,
типографика — по `S8-D/src/s8.css`).

Решения владельца применены во всех кадрах: акцент — синий #0067C0 (фирменный знак, календарный глиф
и категория «Тендеры» — розовые по DESIGN.md), плотность мобильного списка по умолчанию — обычная
с превью, вид потока по умолчанию — группировка, шов «Каналы» скрыт до запуска чата
(дополнение — в `docs/decisions/2026-11-20-webmail.md`, раздел «Решения владельца» ниже).

Каждый кадр — самодостаточный HTML (инлайн-CSS, системный fluent-подобный шрифтовой стек,
значки — Fluent-подобные контурные SVG) и его PNG-рендер: десктоп 1440×900, мобильный 390×844.
Перерендер: `"chrome" --headless=new --window-size=1440,900 --screenshot=01-mail-desktop.png 01-mail-desktop.html`.

## Где какие правила DESIGN.md применены

- **Три-панель без рейла; «Новое письмо» — одна акцентная кнопка в командной строке; поиск там же** — кадры 01–03 (командная строка над деревом/списком, как в S8-D).
- **Разделы значками в области заголовка (Ctrl+1…4), вкладки — только открытые объекты** — кадры 01–02: значки 20 px на кнопках 34×30, выбранный на светлой плашке с контуром; вкладка письма — значок по типу объекта цветом раздела (конверт синий), активная вкладка — текст полужирный и черта 2 px акцентом. «Задачи» (Ctrl+4) показаны неактивной — модуль идёт волной следом (решение 2026-11-20); место зарезервировано.
- **Без модальных окон; тосты с «Отменить»** — кадр 02: тост «Отправлено · Отменить» как inline-карточка в стопке внизу справа над строкой состояния («Отменить» возвращает письмо в композер).
- **Строка письма и метки**: имя отправителя, время справа; метки справа, категория первой; цветная полоса категории слева; регистр меток — с заглавной только первое слово («Ждём ответа»); срок впереди — янтарный текст с часами без подложки («До ср»), просрочено — плотная янтарная заливка («Просрочено 1 д»); «Ждём ответа» — нейтральный серый — кадры 01, 04–06.
- **Быстрые фильтры** — порядок по срочности «Угрозы → Срок → Ждём → Мне → Истекают», равная ширина; значки: щит с красным только у «Угроз», часы янтарные у «Срок»/«Истекают» — кадры 01 (закладки поверх нижнего края карточки списка), 04/06 (чипы с горизонтальной прокруткой).
- **Беседы** — вид по умолчанию — **группировка** (решение 20.11): в списке поток свёрнут в строку со счётчиком («3 письма», «5 писем»), в панели чтения — строка «Беседа: N писем · участников · Развернуть все» (кадр 01); переключатели «Стопка в панели чтения» и «В списке, как Outlook» из Postman останутся в настройках чтения.
- **Приглашение в письме** — карточка над телом: детали (дата, время, место, организатор, «2 из 5 приняли»), лента «Ваш день» (свои события серые, приглашение — полупрозрачный акцент с пунктиром, пока нет ответа; линия «сейчас» — акцентом, не красная), кнопки «Принять» (заливка) / «Под вопросом» / «Отклонить» (тонированные) со значками ✓ ? ✕ в круге, подпись «Ответ уйдёт через календарь сервера» — кадры 01 (вертикальная лента дня, как в Г1) и 05 (компактная).
- **HTML-письма** — внешние картинки по умолчанию скрыты (баннер с «Загрузить / Всегда для отправителя»); несовпадение текста и адреса ссылки — предупреждение; красная подложка — потому что это безопасность — кадры 01, 05.
- **Цвет**: акцент — синий #0067C0 (решение владельца); главное действие — заливка акцентом; второстепенные кнопки — тонированные без рамки («Сохранить черновик», «Под вопросом», «Отклонить»); красный — только безопасность (полоса подменённой ссылки, щит «Угроз»); фирменный знак, календарный глиф и категория «Тендеры» — розовые по DESIGN.md (палитра макета, не акцент); линия «сейчас» в ленте дня — акцентом (синий), не красная; янтарный — только сроки; категория — точка/подложка/текст одного оттенка; тёмная тема — яркие цвета приглушены (заливка акцентной кнопки #2B6CA8, текстовый акцент #7CC4F0) — все кадры.
- **Выделенная строка списка** — тон акцента (#D1E4F4 светлая, #2B3E50 тёмная) + полоса акцента слева; вторичный текст на выделенной строке проверен на контраст ≥ 4,5:1 (кадры 01, 03; T1-D, вариант B).
- **Тёмная тема: окно темнее карточек** — кадры 03, 06 (T1-D, вариант D1: #0F1317 окно, #141A20 карточки).
- **Плотности** — «Обычная» (аватар, тема и текст превью) — по умолчанию (решение 20.11); «Компактная» (без аватара и превью) — переключается в настройках — кадр 06.
- **Мобильный паттерн** (WEB-08) — список и чтение стеком, выдвижные папки (значок меню), нижняя навигация Почта/Календарь/Контакты, FAB «Новое», свайпы с цветными подложками, pull-to-refresh — кадры 04–06.
- **Строка состояния** — «Синхронизировано», квота ящика с полосой — кадры 01–03.
- **Шов «Каналы»** — скрыт до запуска чата (решение 20.11): в дереве папок пункта нет (кадры 01/03 переработаны), резерв — в маршрутах веб-клиента, не в видимой навигации; на мобильной нижней навигации — Почта/Календарь/Контакты, «Каналы» появится при запуске чата.

## Цвета и токены

Веб-сборка берёт цвета из `design/tokens.toml` (решение DES-01: единственный источник). Акцент по решению
владельца 20.11 — синий #0067C0 из DESIGN.md (розовый токен `brand.pink` в интерфейсе отменён; синий #177CAA
остаётся рамкой активной панели/информационным). В макетах:

- поверхности, текст, рамки, статусы ok/warn/err — `[mode.light]` / `[mode.dark]` из `tokens.toml`
  (screen/panel/text/muted/frame/frameA/ok/warn/err);
- акцент (таблица DESIGN.md «Акцент»): заливка главного действия, ссылки, счётчики, черта активной вкладки,
  FAB, линия «сейчас» — #0067C0; тёмная тема — заливка #2B6CA8, текст/ссылки/линия «сейчас» #7CC4F0;
  белый на акцентных кнопках — 5,67:1 (#0067C0) и 5,51:1 (#2B6CA8), ≥ 4,5:1;
- тонированные кнопки и чипы — #DFF0FF/#234E82 (тёмная #23364F/#BFDDFF); тонированная кнопка никогда не
  совпадает с поверхностью, на которой лежит;
- выделенная строка списка — столбцы «Строка списка» таблицы DESIGN.md: #D1E4F4 (тёмная #2B3E50) с полосой
  акцента слева; вторичный текст на ней затемнён (#575757) / осветлён (#BFDDFF) до ≥ 4,5:1 (5,55 / 7,86);
- категории — столбцы таблицы DESIGN.md; «Тендеры» — розовый бренда (#E4107F точка/полоса, чип
  #FCE4EF/#8C0B4E; тёмная #D2569A, #3A1A2A/#F0A8CA) — у DESIGN.md явное исключение для «Тендеров»
  (близость к красному безопасности ΔE ≈ 19 — решение владельца 21.10);
- значки разделов и действий — цвета `icon.*` из DESIGN.md: функциональные глифы — синие (`icon.blue`
  #2F6DB5, тёмная #74A6E0), календарный глиф — розовый (`icon.pink` #C2477F, тёмная #E68AB5) — палитра
  макета, не акцент;
- знак приложения — «Ленты» по спецификации DESIGN.md: полосы синяя #0067C0, стальная #177CAA,
  розовая #E4107F (единый знак в светлой и тёмной теме);

ΔE2000: акцент #0067C0 от красного безопасности #C62828 — 45,4 (тёмная #2B6CA8/#7CC4F0 ↔ #FF5C5C —
47,8–52,5) — близких цветов нет. Розовые элементы (знак, календарный глиф, «Тендеры») — палитра макета
по DESIGN.md: близость розового бренда к красному безопасности (ΔE ≈ 19) — явное исключение DESIGN.md
(решение владельца 21.10, для «Тендеров»/свободного времени); календарный глиф и красный значок
безопасности в одном списке не встречаются (правило значков DESIGN.md). Пара «акцент ↔ чип «Клиенты»»
(12,2/18,0) унаследована от утверждённого DESIGN.md (T1-D: синий акцент и синий чип «Клиенты» в одном списке).

Контрасты пар «текст/фон» проверены (WCAG): основной и вторичный текст ≥ 4,5:1 во всех темах, на выделенной
строке вторичный текст ≥ 4,5:1, белый на акцентных кнопках ≥ 4,5:1, значки ≥ 3:1.

## Решения владельца (20.11) и открытые вопросы

Решения по открытым вопросам макетов приняты 20.11 (дополнение — в конце
`docs/decisions/2026-11-20-webmail.md`) и применены в кадрах:

1. **Плотность по умолчанию** — обычная с превью (кадр 06 слева); компактная переключается в настройках.
2. **Вид потока по умолчанию** — группировка (кадр 01); переключатели «Стопка в панели чтения» и
   «В списке, как Outlook» из Postman останутся в настройках чтения.
3. **Акцентный цвет** — синий #0067C0 (решение владельца). Фирменный знак, календарный глиф и категория
   «Тендеры» — розовые по DESIGN.md (палитра макета, не акцент); коррекция владельца: розовое не
   уничтожать, а использовать как в макете.
4. **Шов «Каналы»** — скрыт до запуска чата: резервируется в маршрутах веб-клиента, в навигации не
   показывается (кадры 01/03 переработаны); на мобильной нижней навигации — без изменений.

Открытых вопросов по макетам не осталось: все четыре решения применены, «Тендеры» — розовый по таблице
DESIGN.md.

Мелкие решения, принятые по умолчанию (можно поменять): свайп «Удалить» на мобильном — графитовая подложка,
не красная (красный — только безопасность; в mobile Outlook delete красный); раздел «Задачи» в заголовке —
неактивная кнопка до своей волны; лента дня в мобильной карточке приглашения — горизонтальная (экономит
высоту экрана); «Копия» свёрнута в подсказку поля.
