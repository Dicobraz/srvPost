# Дизайн-макеты веб-клиента (mod-webmail) — на утверждение

Макеты оболочки веб-почты до старта волны 3 (WEB-03 «Список и чтение»). Дизайн-эталон —
`postman/docs/DESIGN.md` (три-панель Outlook, без модалок, Fluent-темы, правила цвета);
мобильный паттерн — mobile Outlook (решение 2026-11-20-webmail.md, WEB-08). Стиль рамок
выровнен по утверждённым десктоп-макетам `postman/docs/design/S8-D` (пропорции, хром,
типографика — по `S8-D/src/s8.css`).

Каждый кадр — самодостаточный HTML (инлайн-CSS, системный fluent-подобный шрифтовой стек,
значки — Fluent-подобные контурные SVG) и его PNG-рендер: десктоп 1440×900, мобильный 390×844.
Перерендер: `"chrome" --headless=new --window-size=1440,900 --screenshot=01-mail-desktop.png 01-mail-desktop.html`.

## Где какие правила DESIGN.md применены

- **Три-панель без рейла; «Новое письмо» — одна акцентная кнопка в командной строке; поиск там же** — кадры 01–03 (командная строка над деревом/списком, как в S8-D).
- **Разделы значками в области заголовка (Ctrl+1…4), вкладки — только открытые объекты** — кадры 01–02: значки 20 px на кнопках 34×30, выбранный на светлой плашке с контуром; вкладка письма — значок по типу объекта цветом раздела (конверт синий), активная вкладка — текст полужирный и черта 2 px акцентом. «Задачи» (Ctrl+4) показаны неактивной — модуль идёт волной следом (решение 2026-11-20); место зарезервировано.
- **Без модальных окон; тосты с «Отменить»** — кадр 02: тост «Отправлено · Отменить» как inline-карточка в стопке внизу справа над строкой состояния («Отменить» возвращает письмо в композер).
- **Строка письма и метки**: имя отправителя, время справа; метки справа, категория первой; цветная полоса категории слева; регистр меток — с заглавной только первое слово («Ждём ответа»); срок впереди — янтарный текст с часами без подложки («До ср»), просрочено — плотная янтарная заливка («Просрочено 1 д»); «Ждём ответа» — нейтральный серый — кадры 01, 04–06.
- **Быстрые фильтры** — порядок по срочности «Угрозы → Срок → Ждём → Мне → Истекают», равная ширина; значки: щит с красным только у «Угроз», часы янтарные у «Срок»/«Истекают» — кадры 01 (закладки поверх нижнего края карточки списка), 04/06 (чипы с горизонтальной прокруткой).
- **Беседы** — в списке поток свёрнут в строку со счётчиком («3 письма», «5 писем»); в панели чтения — строка «Беседа: N писем · участников · Развернуть все» (кадр 01).
- **Приглашение в письме** — карточка над телом: детали (дата, время, место, организатор, «2 из 5 приняли»), лента «Ваш день» (свои события серые, приглашение — полупрозрачный акцент с пунктиром, пока нет ответа; линия «сейчас» — акцентом, не красная), кнопки «Принять» (заливка) / «Под вопросом» / «Отклонить» (тонированные) со значками ✓ ? ✕ в круге, подпись «Ответ уйдёт через календарь сервера» — кадры 01 (вертикальная лента дня, как в Г1) и 05 (компактная).
- **HTML-письма** — внешние картинки по умолчанию скрыты (баннер с «Загрузить / Всегда для отправителя»); несовпадение текста и адреса ссылки — предупреждение; красная подложка — потому что это безопасность — кадры 01, 05.
- **Цвет**: главное действие — заливка акцентом; второстепенные кнопки — тонированные без рамки («Сохранить черновик», «Под вопросом», «Отклонить»); красный — только безопасность (полоса подменённой ссылки, щит «Угроз»); линия «сейчас» в ленте дня — акцентом, не красная; янтарный — только сроки; категория — точка/подложка/текст одного оттенка; тёмная тема — яркие цвета приглушены (акцентная кнопка темнее, текстовый акцент светлее) — все кадры.
- **Выделенная строка списка** — тон акцента приглушённый + полоса акцента слева; вторичный текст на выделенной строке проверен на контраст ≥ 4,5:1 (кадры 01, 03; T1-D, вариант B).
- **Тёмная тема: окно темнее карточек** — кадры 03, 06 (T1-D, вариант D1: #0F1317 окно, #141A20 карточки).
- **Плотности** — «Обычная» (аватар, превью) и «Компактная» (без аватара и превью) — кадр 06.
- **Мобильный паттерн** (WEB-08) — список и чтение стеком, выдвижные папки (значок меню), нижняя навигация Почта/Календарь/Контакты, FAB «Новое», свайпы с цветными подложками, pull-to-refresh — кадры 04–06.
- **Строка состояния** — «Синхронизировано», квота ящика с полосой — кадры 01–03.
- **Шов «Каналы»** — неактивный пункт внизу дерева папок с пометкой «скоро» (кадр 01); в мобильной нижней навигации раздела «Каналы» пока нет — см. вопросы.

## Цвета и токены

Веб-сборка берёт цвета из `design/tokens.toml` (решение DES-01: единственный источник). В макетах значения
токенов перенесены вручную в CSS-переменные и дополнены утверждённой таблицей DESIGN.md там, где у токенов
нет своей роли:

- поверхности, текст, рамки, статусы ok/warn/err, выделение — `[mode.light]` / `[mode.dark]` из `tokens.toml`
  (screen/panel/text/muted/frame/frameA/ok/warn/err/sel);
- акцент главного действия — `brand.pink` → для заливки кнопки утверждённое значение `sel` #E3107F (белый текст
  ≥ 4,5:1, решение владельца 14.11), текст-акцент/ссылки — `titleA` #C0106B (светлая) / #FB5FB0 (тёмная);
  в тёмной теме заливка кнопки приглушена (#C0106B), как пара «заливка/текст» у Fluent-акцента в DESIGN.md;
- категории (Клиенты/Команда/Тендеры/Пентест/Сервисы), подложка угрозы и сроки, лента дня — столбцы «Светлая» /
  «Тёмная» таблицы DESIGN.md;
- значки разделов и действий — цвета `icon.*` из DESIGN.md (синий/розовый/зелёный/янтарный/красный);
- синяя подложка метки «Клиенты» и тонированные кнопки — тон акцента; тонированная кнопка никогда не совпадает
  с поверхностью, на которой лежит.

Контрасты пар «текст/фон» проверены (WCAG): основной и вторичный текст ≥ 4,5:1 во всех темах, на выделенной
строке вторичный текст затемнён/осветлён до ≥ 4,5:1, белый на акцентной кнопке 4,5:1, значки ≥ 3:1.

## Открытые вопросы — требует решения владельца

1. **Плотность по умолчанию.** В кадре 01 список показан в компактном виде (2 строки, без аватаров — как в S8-D);
   кадр 06 показывает обе плотности на мобильном. Какая плотность — по умолчанию в вебе (и одна ли она для
   десктопа и телефона)?
2. **Вид потока (беседы) по умолчанию.** «Стопка в панели чтения» (карточки от старых к новым) или «В списке,
   как Outlook» (голова беседы + строки писем)? В кадре 01 показан нейтральный вариант: свёрнутый хвост беседы
   и развёрнутое последнее письмо с чипом «3 письма».
3. **Акцентный цвет.** DESIGN.md Postman утверждает синий акцент (#0067C0; тёмная тема #2B6CA8/#7CC4F0);
   токены srvPost (`design/tokens.toml`, DES-01) задают акцентом розовый бренда #E4107F (синий #177CAA —
   основной/рамки). В макетах взят токен бренда (розовый). Это стоит подтвердить или сменить, потому что
   розовый бренда стоит от красного безопасности ближе ΔE2000 25 (в DESIGN.md исключение одно и оно —
   свободное время/«Тендеры»): в кадрах 01/03 акцентная кнопка и красная полоса угрозы видны одновременно.
   Варианты: оставить розовый бренда (как в макетах) / взять синий #177CAA из токенов / взять синий Postman
   #0067C0. Правка механическая — все цвета в макетах в одном блоке `:root`.
4. **Поведение шва «Каналы».** В десктоп-дереве показан неактивный пункт «Каналы · скоро» (кадр 01):
   открывать ли по щелчку карточку-заглушку «Каналы появятся позже» (как пустые состояния каналов в DESIGN.md)
   или скрывать пункт до запуска чатов? В мобильной нижней навигации (WEB-08: три пункта) «Каналы» не показан
   вовсе — добавлять четвёртым пунктом при запуске или держать место?

Мелкие решения, принятые по умолчанию (можно поменять вместе с ответами): свайп «Удалить» на мобильном —
графитовая подложка, не красная (красный — только безопасность; в mobile Outlook delete красный); раздел
«Задачи» в заголовке — неактивная кнопка до своей волны; лента дня в мобильной карточке приглашения —
горизонтальная (экономит высоту экрана); «Копия» свёрнута в подсказку поля.
