# FIX-26: автообновление стенда — timer и СТАТУС — ручная проверка

Нужен: хост-управитель стенда (например, school-99, каталог `~/thepost-d7`), обновлённый
`deploy/stand/stand-update.sh` из репозитория.

## Установка расписания
1. `./stand-update.sh --install-timer` — без root: файлы `stand-update-<каталог>.service/.timer`
   подготовлены рядом, в выводе — две команды `sudo cp … && sudo systemctl enable --now …`.
2. Выполнить их (один раз); `systemctl list-timers | grep stand-update` — таймер в списке,
   `OnCalendar` соответствует `UPDATE_EVERY_DAYS` из update.conf.
3. Под root (`--install-timer` от root) юниты ставятся сами, вывод — «timer установлен».
4. Запасной путь без root: `--install-cron` — строка в crontab (как прежде); у обоих вариантов
   двойной запуск безопасен (lock-каталог).

## Строка СТАТУС
1. Ручной вызов при актуальной версии: последняя строка журнала — «СТАТУС: ok».
2. Во время идущей установки/прогона: параллельный вызов — «обновление уже выполняется» либо
   «СТАТУС: skip» (занятость стенда).
3. `AUTO_UPDATE=no` в update.conf: вызов — «автообновление выключено…» и «СТАТУС: skip».
4. `--check` при наличии новой версии: «доступна новая версия…» (exit 2) и «СТАТУС: ok».
5. Скачивание тарболла в журнале — без прогресс-баров curl.
6. Срыв установки (искусственно: неверный ANSIBLE_IMAGE в update.conf): «СТАТУС: fail»,
   откат на предыдущую версию выполнен, маркер не изменился.
