# PLT-40 — ACME: короткие сертификаты (доля срока, doctor, ARI)

Место: встроенный ACME-клиент (`tp-platform/src/acme.rs`, instant-acme), секция `acme`,
doctor (проверки сертификатов). Ballot SC-081v3 (RFC 9773): сроки жизни публичных
сертификатов — 200 дней с 03.2026, 100 с 03.2027, 47 с 03.2029; у Let's Encrypt уже есть
профиль на 6 дней. Вердикт владельца 20.11 — принять в план.

## Сделать

- Окно перевыпуска — по доле срока вместо фиксированных 30 дней (короткие серты:
  перевыпуск на заметной доле срока, например 1/3), параметр в секции `acme`.
- Ранняя ротация по ARI (renewalInfo — instant-acme 0.8.5 умеет): слушать окно от
  сервера ACME, при замене сертификата CA — перевыпуск вне расписания.
- doctor: предупреждение, если текущий сертификат старше доли срока (или окно
  перевыпуска конфигурацией не достижимо для коротких профилей).
- Документация: требование видимости 80-го порта со всех точек для коротких
  профилей (INSTALL/PREREQUISITES).

## Приёмка

- Тесты: перевыпуск по доле срока (виртуальное время), ARI-окно форсирует
  перевыпуск, doctor предупреждает на коротком профиле.
- Существующие ACME-сценарии (PLT-08) не регрессируют.
