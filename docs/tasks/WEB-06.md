# WEB-06. Календарь: минимум — просмотр и приём встреч

**Класс:** A · **Волна:** `mod-webmail-6` · **Ждёт:** `mod-webmail-3` (WEB-03)

Скоуп v1 по решению 2026-11-20: просмотр + приём/отказ от встреч + ответы iMIP через сервер.
Планировщик встреч с free/busy людей и комнат, ресурсы — после v1.

## Что делает

1. **Просмотр:** день / рабочая неделя / неделя / месяц (JMAP Calendars/CalendarEvent,
   капабилити `calendars`), навигация, «сегодня», свои календари (в т.ч. подписанные
   CalDAV-шaring — из DavStore, read-only достаточно).
2. **Приглашения в почте:** карточка приглашения во входящих с кнопками
   Принять/Возможно/Отклонить → **метод веб-почты JMAP-50** (готов: спам-защита — приглашение
   из «Спама» даёт структурированную ошибку «сначала перенесите письмо»; аудит). Ответ уходит
   iMIP через сервер (тоже метод JMAP-50 пути iTIP).
3. **Создание простой встречи** из календаря: тема, время, участники, комната/ресурс из
   адресной книги — отправка приглашения iTIP через сервер; правка и отмена — UPDATE/CANCEL.
4. **Free/busy чтение** (капабилити `principals:availability`) — подсветка занятости при
   выборе времени (минимум: свои занятые слоты).
5. Push: `CalendarEvent`/`CalendarEventNotification` в уже открытом WS-канале (WEB-03) —
   календарь обновляется живо.

## Приёмка

- Приглашение из Postman → принять в вебе → календарь в Postman показывает «ДА»; обратный
  сценарий симметрично.
- Приглашение в «Спаме» → кнопка даёт ошибку «сначала перенесите письмо»; после переноса — успех.
- Созданная в вебе встреча приходит участнику в Postman карточкой приглашения.
