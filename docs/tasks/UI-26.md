# UI-26. Консоль — управление правилами журналирования (решение #171)

**Класс:** A · **Волна:** `console-17` · **Ждёт:** `admin-39` (ADM-53)

Решение владельца по issue #171. Дополнение страницы «Журнал переписки» (UI-25,
#170): вкладка/раздел «Правила журналирования».

## Сделать

1. На странице журнала (или рядом, видит администратор организации, НЕ аудитор
   журнала — развести роли): список правил (цель: организация/группа/ящик,
   направление In/Out/Both), добавить/изменить/удалить с подтверждением;
   ошибки сервера (RFC 9457) — к форме, дубликат — подсказка.
2. Показ наследования: действующее правило для цели (ящик > группа >
   организация) как в UI-23-стиле «источник значения».
3. Изменение правила — без перезапуска узла (бэкенд читает на каждом письме);
   в интерфейсе предупреждение не нужно.
4. Coverage маршрутов в `api/coverage.ts`; тесты на добавление/изменение/удаление,
   развилку ролей (аудитор журнала правил не видит).
