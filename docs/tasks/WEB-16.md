# WEB-16. Вложения: просмотр, сохранить все, скачать EML

**Класс:** A · **Волна:** `mod-webmail-16` · **Ждёт:** `mod-webmail-4` (WEB-04)

Просмотрщики и выгрузка уровня Postman (attach.preview/save_all, mail.export):

1. **Просмотр** встроенных браузером типов: изображения, PDF, видео/аудио, текст — во вкладке
   чтения (iframe/blob URL, sandbox). WASM-просмотрщики Postman (Office-форматы, архивы) —
   отдельное решение владельца, не в этой волне.
2. **Сохранить все вложения** — blob-download по списку (браузерный multi-download).
3. **Скачать письмо** — EML через blob-download (raw message), доступно для любого письма.
4. Экспорт PST/Maildir — не в вебе (PARITY.md: решение «Postman/CLI»).

## Приёмка

- PDF и изображение открываются во вкладке просмотра, без скачивания на диск.
- «Сохранить все» — файлы приходят, имена сохранены; «Скачать письмо» — валидный .eml, открывается
  в Postman.
- Неизвестный тип — честный отказ с предложением скачать.
