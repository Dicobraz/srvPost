# WEB-17. Задачи (после v1)

**Класс:** B · **Волна:** `mod-webmail-17` · **Ждёт:** v1 (решение владельца)

Перенос tasks.* Postman в веб: список задач (создание/выполнение/срок/редактирование), «открыть
письмо задачи», поручения (delegate/revoke/remind), блок времени в календаре. Серверная основа —
капабилити `tasks` (draft, JMAP Tasks/Calendars) и S6 Postman. В v1 не входит (решение 2026-11-20:
задачи — следующая волна после v1).

## Приёмка (черновик)

- Задача, созданная в Postman, видна и выполняется в вебе; поручение и ответ автору — в обе стороны.
- «Блок времени» создаёт событие календаря.
