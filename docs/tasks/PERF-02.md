# PERF-02 — JMAP Email/query p95 311 мс при пороге 200 мс (Д.7 №1)

Место: `crates/tp-jmap/` (Email/query, Email/get), найдено прогоном Д.7 2026-11-17.

## База

| Прогон | Стенд | query p95 | get p95 |
|---|---|---|---|
| 20261117T174936Z-speed-base | school-99 (8 vCPU, sync_commit=off) | **311 мс** | 383 мс |
| 20261117T182831Z-speed-base | school-99, тише | **311 мс** | 416 мс |
| 20261117T202158Z-speed-base | podium-dev (2 vCPU/3.8G, честный конфиг) | 7.25 с | 11.34 с |

Порог Д.7 №1 — **< 200 мс**. Отказов 0, воспроизводимо 311 мс — стабильный путь, не шум.
На 2 vCPU деградирует в разы: на каждый запрос — заметная работа CPU/СУБД (сортировка/подсчёт?).

## Сделать

- Профилировать Email/query на ящике big (10k): план запроса, число строк, стоимость сортировки.
- Цель: p95 < 200 мс на 4 vCPU/8 GB (эталон Д.2); кандидаты — индекс под сортировку/фильтр по умолчанию,
  кэш списка ID папки, ограничение total (позиционная пагинация вместо COUNT).

Волна: jmap-32 (класс A). Связано: [[PERF-01]].
