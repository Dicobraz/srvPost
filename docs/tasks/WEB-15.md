# WEB-15. Общие ящики, «Взять в работу»

**Класс:** A · **Волна:** `mod-webmail-15` · **Ждёт:** `mod-webmail-3` (WEB-03)

Перенос mail.take («Взять в работу», Ctrl+J) и работы с общими ящиками Postman: серверная
ACL (RFC 4314, tp-auth/authz) уже есть.

## Что делает

1. Открытие общих ящиков, доступных по ACL: дерево/переключатель, чтение, действия в меру прав.
2. «Взять в работу»: взять/вернуть письмо (keyword/state, как в Postman), чтобы «взял я» видели все
   клиенты — формат взять у Postman (сверка keyword).
3. Ответ/отправка от имени общего ящика (Send As / On Behalf — из identity JMAP, ACL есть).
4. Отображение «кто взял» — из keyword/стейта, честное при отсутствии.

## Приёмка

- Общий ящик из Postman открывается в вебе; «взять в работу» видно в Postman и в вебе, конфликт
  одновременного взятия — предсказуем (первый).
- Отправка от общего адреса: From = общий ящик, права по ACL; без права — понятная ошибка.
