# WEB-12. Сервер: лимит JMAP-сессий + фиксация keyword-масок

**Класс:** B · **Волна:** `mod-webmail-12` (межполосный PR: jmap + docs) · **Ждёт:** `mod-webmail-3` (WEB-03)

## Что делает

1. **Лимит параллельных JMAP-сессий на аккаунт** (настраиваемый, в jmap-конфиге): превышение —
   структурированная ошибка JMAP (`limitError`), не молчаливое вытеснение. Мотивация — WEB-03:
   один WS на пользователя делается на клиенте, но чужие клиенты (Postman + веб + Thunderbird)
   легальны — сервер должен ограничивать честно и настраиваемо.
2. **Фиксация keyword-масок** (документация + константы в tp-jmap): сроки/категории в вебе
   (WEB-03 quick-filters «Срок/Ждём/Истекают», клавиши 1–9) работают на keywords Postman
   (`$followup`-семейство, категории 1–9). Сверка: карта «Postman keyword → смысл → окно веба»,
   покрытие серверными тестами на set/get round-trip.

## Приёмка

- Тест: N+1 сессий при лимите N — последняя получает структурированную ошибку, первые не страдают.
- Тест round-trip keywords (set → get) для всех масок карты.
- Документ-карта в `docs/CONTRACTS.md` или jmap-дока (выбор агента).
