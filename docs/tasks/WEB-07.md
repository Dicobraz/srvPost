# WEB-07. Контакты и GAL

**Класс:** A · **Волна:** `mod-webmail-7` · **Ждёт:** `mod-webmail-4` (WEB-04 — autocomplete в композере)

JMAP Contacts (RFC 9610) уже на сервере: личные книги через DavStore, GAL-книга «Организация»
read-only из LDAP/PostgreSQL (`thepost/src/gal.rs`, sync по maintenance-интервалу).

## Что делает

1. **Личная адресная книга:** CRUD карточек (имя, адреса, телефоны, организация, фото),
   группы рассылки (AddressBook-группы RFC 9610), поиск (устойчивость к раскладке — клиентская
   нормализация запроса).
2. **GAL «Организация»:** read-only просмотр, поиск; карточка контакта открывается табом
   (DESIGN.md: контакты — таб, не модалка). Оргструктура (`orgchart`) — если придёт из GAL.
3. **Autocomplete в композере** (дооснащение WEB-04): личные + GAL + история отправок,
   порядок как в Postman (личные выше, «Часто пишу»), раскладко-устойчивый поиск.
4. **Push:** `AddressBook`/`ContactCard` в WS-канале — изменения GAL после sync видны живо.

## Приёмка

- Контакт, заведённый администратором в LDAP, появляется в «Организации» после sync-интервала
  и в вебе, и в Postman; правка из веба невозможна (read-only).
- Autocomplete находит и личный контакт, и GAL-запись; запрос в EN-раскладке находит кириллицу.
- Созданный в вебе контакт мгновенно предлагается в композере Postman (JMAP-контакт общий).
