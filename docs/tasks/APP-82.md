## Сделать
- `doctor journal chain` (и автоматом в общем прогоне): `verify_chain()` — целостность хеш-цепочки индекса, разрыв с номером записи; сверка числа записей индекса и объектов хранилища записей.
- `doctor journal retention`: прогноз объёма бакета журнала — по правилам журналирования, среднему размеру записи и срокам блокировки показать ожидаемый объём на горизонт (риск 21: ошибка в сроке compliance не освобождает бакет); предупреждение при заказанном сроке больше N лет или при прогнозе больше доступного места.
- Профиль SMB (хранилище журнала на локальном диске): предупреждение — блокировка только сервером (append-only), от администратора ОС защиты нет; для неизменяемости — S3 с Object Lock (риск 23).
- Вывод в `--json` для скриптов и стенда (как остальные проверки doctor); причины зависимых проверок явные (по образцу FIX-10).
