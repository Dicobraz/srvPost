# WEB-05. Поиск и фильтры

**Класс:** A · **Волна:** `mod-webmail-5` · **Ждёт:** `mod-webmail-3` (WEB-03)

Серверный FTS уже есть (Tantivy, ru/en стемминг, «ё», текст вложений, сниппеты —
`crates/tp-search`, `Email/query`); веб-клиент должен им правильно пользоваться.

## Что делает

1. **Поиск как в Postman:** по мере набора (debounce), по теме/от/кому/телу, морфология
   («квартала» находит «квартал») — серверная; **транслитерация раскладки на клиенте**:
   запрос `rdfhnfk` перед отправкой пробуется и как «квартал» (qwerty→йцукен) — серверную
   логику не трогаем.
2. **Сниппеты** совпадений в списке результатов (JMAP `Email/query` сниппеты).
3. **Click-refinements:** клик по отправителю/папке/периоду сужает запрос (как в Postman).
4. **Фильтры:** панель фильтров (папка, прочитанность, вложения, флаги, период), quick filters
   под списком ( Threats/Due/Waiting/To me/Expiring — по keywords из WEB-03).
5. Поиск в оффлайне — по локальному кэшу (WEB-09), помечается как «по кэшу».

## Приёмка

- Морфология: «письма о кварталах» находятся запросом «квартал»; запрос в EN-раскладке
  (`rdfhnfk`) находит «квартал».
- Сниппет показывает совпадение; уточнение кликом сужает выборку без перезагрузки страницы.
- Поиск по телу вложения (PDF/Word) находит письмо (сервер уже извлекает текст).
