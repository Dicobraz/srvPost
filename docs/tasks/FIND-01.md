# FIND-01 — SMTP отказы 421 под нагрузкой без причины в журнале узла

Место: `crates/tp-smtp/` (ответ 421) + журнал, найдено прогоном Д.7 2026-11-17 на school-99.

## Что случилось

Прогон 20261117T182831Z-speed-base: входящая нагрузка (smtp-source → 25) — 55 отказов «fail 421»,
зонд smtp — 276 отказов 421 на school-99 в 17:49Z-прогоне. В журнале узла за окно прогона — **ни одной
записи с кодом 421** (только 250/550): узел отвечает 421, не логируя причину. На podium (2 vCPU, та же
нагрузка) — отказов 0–1: похоже на защитное ограничение (лимит соединений/памяти/диска?), которое
срабатывает под нагрузкой на 8 vCPU-хосте и молчит.

## Сделать

- Найти все места ответа 421 в `tp-smtp`; на каждый — причина в журнал (лог-строка с кодом и полем причины).
- При повторном прогоне Д.7 на school-99: причина 421 в журнале → карточка FIX/PERF на сам лимит
  (если лимит осознанный — проверить пороги против Д.7, если нет — исправить).

## Приёмка

- Прогон с отказами 421 → в журнале узла строки «421: <причина>» на каждый отказ.
