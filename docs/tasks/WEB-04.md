# WEB-04. Композер: rich text, вложения, undo-send

**Класс:** A · **Волна:** `mod-webmail-4` · **Ждёт:** `mod-webmail-3` (WEB-03)

Паритет с композером Postman по DESIGN.md: таблицы, вставка из Word, подпись,
drag-drop вложений, undo-send ~15 с, предупреждения.

## Что делает

1. **Редактор — TipTap:** таблицы (создание/правка), вставка из Word с сохранением
   структуры (списки, таблицы, жирность; мусор Word-стилей вычищается), подпись с
   логом-картинкой (inline-блобом). HTML письма — обычный multipart от EmailSubmission.
2. **Получатели:** Кому/Копия/Скрытая, autocomplete (контакты + GAL + история — WebView:
   до WEB-07 история локальная по отправленным), пикер «Кому…» (адресная книга),
   Send As / On Behalf (ACL `tp-auth/authz` — из identity JMAP).
3. **Вложения:** drag-drop и пикер → `POST /jmap/upload/{account}/`, прогресс и отмена;
   отдача — стримом (без буферизации файла в память вкладки), крупные — через File API
   частями. Лимиты сервера (`maxSizeUpload`) — честные ошибки при превышении; попытка
   залить гигабайт не должна выедать память ни вкладки, ни узла (download на сервере уже
   стримится, upload — проверяется в волне).
4. **Черновики:** автосохранение в Drafts (Email/set), восстановление после закрытия вкладки
   (черновик сервера — источник истины), Ctrl+Z-цепочка редактора.
5. **Отправка + undo:** EmailSubmission; окно ~15 с с тостом «Отменить» — уничтожение
   submission до фактического выхода (идемпотентность: undo после ухода почты невозможен —
   тост честно пропадает). Отправка офлайн — очередь WEB-09.
6. **Предупреждения (как в Postman):** «прилагаю» без вложений; внешние получатели
   (не из домена/контактов); пустая тема. Inline-подтверждение, не модалка.

## Приёмка

- Письмо с таблицей из Word читается в Postman и Outlook без развала вёрстки.
- Undo возвращает письмо в черновики в течение окна; после окна письмо реально уходит
  (видно на стенде в очереди/логе доставки).
- Черновик сохранён при падении вкладки — открывается из Drafts.
- Предупреждение о забытой вложенности срабатывает на «прилагаю», не срабатывает без слов о вложении.
