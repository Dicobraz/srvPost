## Сделать
- Страница «Журнал переписки» (отдельная от журналов доставки/аудита): видна только роли `journal-auditor`; поиск по отправителю, получателю, Message-ID, интервалу, правилу; список записей (время, отправитель, получатели, правило), просмотр конверта, выгрузка `.eml`.
- Отчёт целостности: индикатор `verify chain` и ссылка на отчёт (число проверенных записей, разрыв).
- Управление правилами журналирования (организация/группа/ящик, направление) — отдельная вкладка администратора или внутри страницы по роли: создание/выключение правила; содержание писем в списке правил не показывается.
- Тема и токены — design (DES-01); локализация i18n.

## Как делают другие
- Exchange EAC/Purview: eDiscovery-поиск для комплаенс-роли и настройки journaling для администратора — разные экраны.

## Приёмка
- `console`-тесты: страница по роли `journal-auditor` доступна, остальным ролям скрыта; поиск и выгрузка вызывают Admin API; изменение правил журналирования сохраняется.
