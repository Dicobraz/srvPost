# WEB-13. Полный планировщик встреч + календари рядом/наложением

**Класс:** A · **Волна:** `mod-webmail-13` · **Ждёт:** `mod-webmail-6` (WEB-06)

Помощник планирования уровня Postman (meeting.* реестра): сетка недели по участникам
(и комнатам/ресурсам), свободные окна из free/busy (`principals:availability`), выбор слота
курсором/клавишами, длиннее/короче на шаг сетки, добавление участников из справочника,
«написать участникам». Плюс два календаря рядом или наложением (`calendar.side_by_side`).

## Приёмка

- Создание встречи через планировщик: выбираются только окна, свободные у всех обязательных
  участников; конфликты видны; приглашение iTIP уходит (iMIP сервером).
- Клавиатурная навигация слотов (next/prev/longer/shorter/enter) — как в Postman.
- Два своих календаря рядом и наложением; события обоих видны.
