# WEB-19. Напоминания: постоянная поверхность «всегда перед глазами»

**Класс:** A · **Волна:** `mod-webmail-19` · **Ждёт:** `mod-webmail-15` (полоса web занята волной 15 на момент заведения; по данным — достаточно mod-webmail-3)

Решение владельца 21.11: «напоминания должны появляться и висеть каким-то фоном, чтобы были
всегда перед глазами» — пользователь никогда ничего не держит в голове, интерфейс напоминает сам.
Keyword-основа уже стандартизована (WEB-12/CONTRACTS: `pm.due[.дата[tЧЧММ]]`, `pm.wait`,
`pm.expire`, `pm.threat`), отображение меток в списке есть (WEB-03: «До ср», «Просрочено»).

## Что делает

1. **Установка напоминания из письма:** контекст-меню/команды — «Напомнить…» (inline-пикер
   даты-времени → `pm.due.<дата>t<ЧЧММ>`), «Ждать ответа» (`pm.wait`, дата опциональна),
   «Исчезнет…» (`pm.expire`); «Снять напоминание» — убрать keyword. Email/set, живое по push.
2. **Постоянная полоса «Напоминания» в оболочке** — видна на ВСЕХ разделах (Почта/Календарь/
   Контакты/Композер), компактная, сворачивается в счётчик:
   - «Просрочено» — янтарным (правило DESIGN.md: янтарный = сроки; красный не трогаем),
   - «Сегодня», «Далее» (ближайшие),
   - «Ждём ответа» (`pm.wait`),
   - счётчик + ближайшие N тем писем; клик по секции → отфильтрованный список, клик по письму →
     открытие письма. Обновление живое (push/delta уже есть).
3. **Мобильный:** полоса — постоянный чип над нижней навигацией, разворот тем же жестом.
4. Сверка отображения меток с каноном keyword (WEB-12 карта) — «До ср»/«Просрочено N д»
   считаются от `pm.due.<дата>t<ЧЧММ>`.

## Открытый вопрос владельцу (в PR)

«Возвращается во Входящие» после срока — в Postman это делает клиент, пока он запущен.
Для веба: (а) достаточно полосы «Напоминания» (письмо остаётся где лежит), или (б) нужен
серверный механизм возврата во Входящие (полоса jmap, отдельное решение)? v1 — (а).

## Приёмка

- Полоса видна на всех разделах и после перезагрузки; «Напомнить завтра 9:00» появляется в
  «Далее», через сутки — в «Просрочено» (янтарным).
- Клик по секции/письму ведёт куда обещано; снятие keyword убирает из полосы живо (push).
- Хоткеи/палитра: «Напомнить…» доступна командой (Ctrl+J свободен? — нет, занят take: своя
  клавиша по свободному слоту PARITY, например Ctrl+.).
