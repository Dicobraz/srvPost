# PERF-04 — индексация письма не завершается: зонд «index» не находит письмо за 180 с (Д.7 №10)

Место: индексация/поиск (`crates/tp-mailstore/` или `crates/tp-jmap/` Email/query text), найдено прогоном
Д.7 2026-11-17.

## База

| Прогон | Стенд | итог |
|---|---|---|
| 20261117T174936Z / 182831Z | school-99 | «не найдено 54/55» из 64 замеров |
| 20261117T202158Z | podium-dev | «не прошёл» (не найдено) |

Зонд шлёт письмо с уникальным словом на порт 25 (внутренний ящик probe1), затем раз в секунду
`Email/query {"filter": {"text": <слово>}}` до 180 с. Письмо доставляется (критерий №4 на podium с
FIX-14 даёт замеры, потери 0), но поиск его не находит: либо письмо индексируется с задержкой > 180 с,
либо `Email/query text` ищет не по тому полю (заголовки/тело?), либо индексация падает молча.

## Сделать

- Воспроизвести локально: письмо через SMTP → `Email/query text` — находит/нет; журнал узла при
  индексации (ошибки?); какие поля входят в `text`.
- Починить (задержка > 180 с — это тоже «не прошёл»: порог №10 — p95 индексации < 60 с).
- Приёмка: Д.7 №10 — замеры есть, p95 < 60 с; №8 (FTS) без каскада от «не найдено».

Волна: mailstore-18 (класс A). Связано: [[PERF-01]], [[PERF-02]] (тот же стенд), FIND-01 (421 без причины
в журнале — наблюдаемость SMTP-отказов под нагрузкой).
