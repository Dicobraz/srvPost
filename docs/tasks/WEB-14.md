WEB-14. Настройки веб-клиента: vacation, правила Sieve, подпись, тема/плотность

**Класс:** A · **Волна:** `mod-webmail-14` · **Ждёт:** `mod-webmail-7` (WEB-07)

Перенос настроек Postman (settings.open/vacation/rules/calendar) в веб:

1. **Автоответы (vacation)** — форма поверх JMAP VacationResponse (капабилити `vacationresponse`
   сервера): включить/выключить, текст, период, адреса-ограничение.
2. **Правила** — UI правил поверх JMAP Sieve (RFC 9661, серверная полоса Sieve есть): условия →
   действия (папка, флаг, категория), безопасная активация/деактивация, тот же порядок редактора
   что в Postman (пользовательская правка НЕ пашет в синтаксис — готовые шаблоны, только
   сервер-совместимые).
3. **Подпись** — редактирование подписи (текст+картинка), хранение как в Postman.
4. **Тема/плотность/размер шрифта** — из wave-1 токенов; выбор темы системная/светлая/тёмная
   уже есть — дополнить плотностью списка и шрифтом.

## Приёмка

- Vacation: включённый автоответ реально отвечает (стенд), выключение мгновенно.
- Правило «от <адрес> → в папку X» работает серверно (письмо раскладывается при закрытом вебе).
- Подпись в новых письмах веба; тема/плотность применяются без перезагрузки.
