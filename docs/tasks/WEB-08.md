# WEB-08. Мобильный layout + PWA

**Класс:** A · **Волна:** `mod-webmail-8` · **Ждёт:** `mod-webmail-3`, `mod-webmail-4` (композер-стек)

Один код с десктопом; паттерны — mobile Outlook (решение 2026-11-20). Нативные приложения
не в v1 (SRS: «нативное приложение или PWA» — выбрано PWA).

## Что делает

1. **Брейкпоинт (узкий экран):** список и чтение стеком (чтение — «страница» с возвратом),
   нижняя навигация Почта/Календарь/Контакты, FAB «Новое письмо», папки — выдвижная панель.
2. **Жесты:** свайп по строке списка — удалить/архивировать/флаг (настраиваемые), свайп назад
   из чтения, pull-to-refresh (принудительный sync).
3. **PWA:** манифест (имя, иконки, тема, standalone), service worker (vite-plugin-pwa):
   precache ассетов приложения, API-запросы не кэшируются SW-ом (кэш данных — Dexie, WEB-09);
   установка на телефон (Android Chrome / iOS «На экран „Домой“»).
4. **Мобильные нюансы:** клавиатура не перекрывает композер, safe-area, размер тап-целей,
   тяжёлые письма (большие таблицы) — прокрутка без деградации.

## Приёмка

- Реальный телефон (Android Chrome и iOS Safari): чтение, свайпы, FAB-композер, установка
  PWA, иконка/заставка; обратный выход в десктоп-вид (широкое окно) без регресса.
- Свайп-действия и pull-to-refresh вызывают те же JMAP-операции, что десктопные (без дублей).
