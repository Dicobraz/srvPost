## Сделать
- Решение issue #45 (вариант 1): модуль «шрифт консоли» в `tp-sys` — безопасные функции прочитать шрифт и карту
  Unicode (`KDFONTOP` `KD_FONT_OP_GET`, `GIO_UNIMAP`), подменить четыре глифа под стрелку со сдвигом и вернуть
  при выходе (`KD_FONT_OP_SET`, `PIO_UNIMAP`); `unsafe` (ioctl) — только внутри `tp-sys`, Linux-only.
- Межкрейтовый вызов из `tp-tui` (прямая зависимость от `tp-sys`, точка расширения — публичный API модуля;
  контракт в `tp-contracts` не нужен: типы не покидают границу терминального запуска).
- Текстовый интерфейс (TUI-07, уровень 3 на консоли Linux): при старте — чтение шрифта, выбор четырёх
  свободных позиций и кодов области частного использования, загрузка глифов; при выходе, ошибке и панике —
  возврат шрифта и карты (RAII). Глифы 2×2 со сдвигом — из TUI-07; ячейки курсора печатают коды PUA.
- Запись шрифта требует `CAP_SYS_TTY_CONFIG` (обычно root на консоли узла) и vt-консоль; отказа — уровень 4.

## Приёмка
- Тесты: выбор позиций и кодов по карте Unicode; упаковка глифов в расширенный формат шрифта (32 строки на
  глиф); возврат восстанавливает исходные байты и карту; уровень консоли — загрузка глифов через модуль
  (макет без ioctl), отказ модуля — уровень 4.
- Ручная проверка: консоль Linux на стенде (уровень 3, стрелка следует за мышью из `/dev/input`), выход —
  шрифт и карта прежние; без прав записи — уровень 4.
